BREAKING. Step 02 says it uses non-overlapping 14-day windows, but window k ran from gStart + 14(k−1) to gStart + 14k: consecutive windows shared their boundary day, and every window but the last had 15 days. Window k now covers gStart + 14(k−1) … gStart + 14k − 1 (at most gEnd), in the TAS fits and in the step-04 scenario fits (whose last window still runs to gEnd). The number of windows and the per-year widening of sparse windows (in steps of 3 days, up to 24) are unchanged, so the change is one boundary day per window: the windows' nighttime data, reference temperatures and the site-years kept change slightly.

Result. One day less per window changes every site's fits, by about the size of the MCMC noise times a few: |ΔTAS| median 0.0023 (total) and 0.0028 (direct), up to 0.021 and 0.030; 72 and 83 sites move beyond the threshold. Six total and eight direct estimates change significance class (mostly weak positives becoming not significant, e.g. direct US-NC2 0.029 → 0.012), none flips sign. The future-respiration scenario hardly moves (mean increase 7.23% → 7.27% with total TAS); driver importances shift by up to about 5 percentage points.
