How this site's TAS is estimated

Each two-week window of the growing season gets, in each year, a fitted curve of nighttime respiration against temperature (left). Where the curves sit at the window's reference temperature is that year's reference respiration, ERref; it is compared with the control year's as ln(ERref / ERref, control). Plotted against how warm that window was in that year (middle), and within each window (right), the slope is TAS. See How TAS is estimated.

Left: colours run from the coolest (blue) to the warmest (red) year in the window; ticks mark each year's mean temperature, dots its reference respiration. Middle and right: colours by window through the season; the line is the fitted TAS with ± 1 standard error. The regression behind TAS also allows for correlation between successive years (AR(1)), so the line is not exactly a least-squares fit to these points.
