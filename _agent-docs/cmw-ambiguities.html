US-CMW Soil Water Content Ambiguity

Analysis record, reproducible audit, and approval-gated implementation plan

Issue

The AmeriFlux metadata row for US-CMW currently says to use SWC_PI_F_1_1_A.

The active AmeriFlux workflow reads the configured field literally at 01_02b_filter_high_quality_night_respiration_AmeriFlux.R:218-233, interpolates short gaps, and later requires non-missing SWC when preparing the measured nighttime data for the water-mediated model.

That mapping is ambiguous for two independent reasons.

  1. SWC_PI_F_1_1_A is not present in the local current US-CMW archive.
  2. The archive contains two plausible raw fields, SWC_1_6_1 and SWC_1_7_1, but their values differ materially.

The old field name therefore cannot be treated as a harmless alias, and the two current fields cannot be averaged or substituted without deciding what sensor level and definition the analysis requires.

Depth note: The general AmeriFlux naming convention indicates that SWC_1_6_1 and SWC_1_7_1 share horizontal profile index 1 and replicate index 1, while their vertical/depth ranks differ (6 versus 7).

This suggests that they are measurements at different depths in one soil profile rather than redundant sensors at one depth.

The actual US-CMW depths, instrument setup, and any site-specific naming exceptions could not be confirmed from the locally bundled BADM workbook or public site materials.

Evidence

The analysis used data-raw/AMF_US-CMW_BASE-BADM_3-5.zip, read with amerifluxr::amf_read_base().

The archive contains the 2001–2021 half-hourly flux file and a BADM workbook, but the workbook has no SWC variable-definition rows that resolve the two field names.

The audit excludes the existing pre-2001 records because the production workflow truncates US-CMW to YEAR > 2000.

How Other Code Handles SWC

  • AmeriFlux sites generally select one explicit sensor-level field in data/site_info.csv; there is no general cross-sensor averaging rule.
  • US-NR1 selects a measured SWC field and fills only its missing values from SWC_PI_1.
  • US-ChR explicitly uses a deeper SWC field because the first layer is documented as abnormal.
  • Some sites with SWC_use = NO omit measured SWC and 02_01b joins daily ERA5-Land soil water content instead.
  • ICOS data use the normalized aggregate field SWC_F_MDS_1; that is a different source convention and should not determine the AmeriFlux sensor choice.
  • FR-Pue is a separate exception that reads PI-provided SWC files and applies a documented unit conversion.

Recommendation

Do not retain the stale SWC_PI_F_1_1_A mapping and do not silently average the two fields.

Use SWC_1_6_1 for US-CMW for now because its lower vertical index is the shallower candidate.

Treat this as a provisional choice until authoritative documentation confirms the actual depths, units, instrument setup, and whether either field is PI gap-filled.

If later documentation contradicts the naming-based depth interpretation, revisit the mapping and consider a sensitivity analysis for SWC_1_6_1 and SWC_1_7_1.

A row-wise mean is available as an exploratory option, but I do not recommend it as the default because it creates a new aggregate variable, obscures the sensor-depth meaning, and is not how the other AmeriFlux sites are currently handled.

Implementation Plan

  1. Confirm the definitions and actual depths of SWC_1_6_1 and SWC_1_7_1 using authoritative US-CMW source documentation.
  2. Record the provisional selection of SWC_1_6_1, the unresolved depth evidence, and the rationale in the project metadata and relevant workflow documentation.
  3. Keep the demonstration metadata unchanged unless it is explicitly intended to remain synchronized with the active site metadata.
  4. Add a focused validation that fails clearly when the configured SWC field is absent from the archive, rather than allowing a stale mapping to fail later.
  5. Run the AmeriFlux workflow for US-CMW with overwrite enabled and inspect coverage, missingness, and the resulting nighttime SWC records.
  6. Rerun the water-mediated downstream model for US-CMW and compare its results with the prior output where that comparison is meaningful.
  7. Run syntax checks and review the generated aggregate outputs for duplicate or stale US-CMW rows.
  8. Document the final decision and verification results here.

Current status: The analysis, audit scripts, and figures are complete. The active metadata now maps US-CMW to the provisional shallower candidate SWC_1_6_1; no workflow code has been changed.

Follow-up: Verify the actual sensor depths and setup from BADM, the AmeriFlux Variable Info tool, or the site PI, then revise the mapping if needed.
