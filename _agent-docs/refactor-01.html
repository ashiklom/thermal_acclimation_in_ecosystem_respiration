Workflow 01 Refactor

Plan and implementation record for 01_01, 01_02a, and 01_02b.

Plan

  1. Keep package loading, input discovery, and the existing site-specific transformations unchanged wherever possible.
  2. Move the body of each existing site loop into a process_site(name_site, ...) function that resolves the matching row in site_info.
  3. Add command-line parsing for an optional comma-separated site list and the --overwrite flag.
  4. When no site list is supplied, derive the candidate sites from site_info and the workflow's supported source or temperature-estimation rules.
  5. Skip a site by default when its per-site output files exist, or when its row already exists in the relevant growing-season aggregate.
  6. When overwriting, process selected sites again and replace their rows in aggregate output rather than appending duplicates.
  7. Validate requested site names and report skipped or unsupported sites clearly.

Implementation Strategy

01_01 will use site_ID as the function input and retain one output file per site in data-raw/TS_RandomForest.

01_02a and 01_02b will return one growing-season feature row from each successful site function call, write the two per-site respiration files, and merge those rows into their existing aggregate CSV.

The command-line form will support both --sites=SITE1,SITE2 and a positional comma-separated site argument, plus --overwrite.

Rscript workflows/01_02c_filter_high_quality_night_respiration_ICOS.R --sites=FR-FBn,FR-Fon
Rscript workflows/01_02b_filter_high_quality_night_respiration_AmeriFlux.R US-Ha1 --overwrite

Implementation Notes

Implementation is intentionally limited to high-level control flow, selection, skip checks, and aggregate-file bookkeeping.

The existing calculations, special cases, diagnostics, and output schemas remain unchanged.

01_01 now processes only requested eligible temperature-estimation sites and skips existing per-site prediction files unless --overwrite is supplied.

01_02a and 01_02b now process only requested sites from their respective source groups, preserve existing aggregate rows, and replace selected aggregate rows during overwrite runs.

Verification

All three scripts parse successfully with Rscript without executing the data-intensive workflow.

git diff --check reports no whitespace errors in the edited workflow files.

The final diff was reviewed for accidental changes inside site-specific processing logic and for correct overwrite behavior.

Execution Test

The end-to-end test used US-Ha1 as the AmeriFlux site and DE-Akm as the EuroFlux site.

FR-FBn was selected because it is an eligible ICOS site with a normalized local input file.

The first pass used --overwrite for both sites.

Rscript workflows/01_01_estimate_soil_temperature_at_some_sites.R --sites=US-Ha1,DE-Akm --overwrite
Rscript workflows/01_02b_filter_high_quality_night_respiration_AmeriFlux.R --sites=US-Ha1 --overwrite
Rscript workflows/01_02c_filter_high_quality_night_respiration_ICOS.R --sites=FR-FBn --overwrite

The successful site-level runs created US-Ha1_TS_rfp.csv, DE-Akm_TS_rfp.csv, both per-site AmeriFlux respiration files, both per-site EuroFlux respiration files, and the corresponding aggregate feature files.

The refactor preserves local data-raw paths, creates respiration output directories automatically, and keeps AmeriFlux timezone handling based on the IANA timezone returned by tz_lookup_coords().

The second pass omitted --overwrite:

Rscript workflows/01_01_estimate_soil_temperature_at_some_sites.R --sites=US-Ha1,DE-Akm
Rscript workflows/01_02b_filter_high_quality_night_respiration_AmeriFlux.R --sites=US-Ha1
Rscript workflows/01_02c_filter_high_quality_night_respiration_ICOS.R --sites=FR-FBn

All three skip runs exited successfully without re-running the data-processing calculations.
