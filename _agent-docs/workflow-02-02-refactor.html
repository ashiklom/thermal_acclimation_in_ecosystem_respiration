Workflow 01-02 Refactor Plan

Merge four source-specific scripts (01_02a-d) into a single unified dispatcher (01_02) that routes by site_info.csv$source. Follows the same structural pattern as workflows/01_01_estimate_soil_temperature_at_some_sites.R.

Goal

Consolidate 01_02 (draft), 01_02a (EuroFlux), 01_02b (AmeriFlux), 01_02c (ICOS), and 01_02d (TERN) into:

  • 1 helper file (R/respiration_helpers.R) with shared functions
  • 1 unified script (workflows/01_02_filter_high_quality_night_respiration.R) that dispatches by data source

Output structure simplified: all sites write to a single data-proc/respiration/ directory (no per-source subdirs). A single consolidated data-proc/features/growing_season_features.csv replaces the four per-source feature files. CLI interface (--sites, --overwrite) remains identical.

Architecture

Overall structure: single process_site() function

Follow the same pattern as workflows/01_01_estimate_soil_temperature_at_some_sites.R:

# Single process_site() function
process_site <- function(name_site, overwrite = FALSE) {
  site_info <- get_site_info(name_site)   # returns single-row tibble
  output_source <- site_info[["source"]]  # scalar access, never [id]

  # ... check output exists, skip if not overwrite ...

  # Source dispatch via if/else if
  if (output_source == "TERN") {
    # TERN-specific block
  } else if (output_source == "ICOS") {
    # ICOS-specific block
  } else if (output_source == "AmeriFlux_BASE") {
    # AmeriFlux-specific block (calls process_ameriflux_core() helper)
  } else if (output_source %in% c("FLUXNET", "FLUXNET2015")) {
    # EuroFlux-specific block
  }

  # Common: write outputs, return feature row
}

Key conventions:

  • get_site_info(name_site) returns a single-row tibble; all column access via $ or [["col"]]
  • No [id] indexing anywhere
  • Southern hemisphere detection: site_info[["LAT"]] < 0 consistently (not hardcoded site lists)
  • The AmeriFlux block (~350 lines) is extracted into an internal helper process_ameriflux_core() to keep process_site() readable

Step 1: Extract shared helpers into R/respiration_helpers.R

These functions are duplicated or nearly duplicated across all four scripts:

  • parse_removed_years(value) — parse comma/range year removal strings like "2007:2009, 2013" into integer vector. Exists in 01_02c/01_02d; inline in 01_02a/01_02b.
  • add_timestamp_columns(a, timestamp_col = "TIMESTAMP_START") — parse TIMESTAMP_START, create TIMESTAMP/YEAR/MONTH/DAY/DOY/HOUR/MINUTE. Identical across all scripts.
  • adjust_southern_hemisphere(a, lat) — if lat < 0, shift DOY < 183 by +366. Returns logical. Unified to use LAT < 0 everywhere (not hardcoded site lists).
  • detect_growing_season(nee_yearly, site_info_row, ...) — compute gStart/gEnd/tStart/tEnd from NEE seasonality. The filter threshold differs by source: EuroFlux uses max(min(NEE)*0.2, -0.8), AmeriFlux uses min(NEE)*0.2. Accept a threshold_fn parameter or have the caller pre-filter tmp.
  • build_gs_dates(gStart, gEnd, yStart, yEnd, dt, southern_hemisphere) — create growing-season boundary timestamps for gap detection. Identical across all scripts.
  • filter_good_years(a_measure_night_complete, gStart, gEnd, gap_max_thresh, gap_total_thresh) — year-gap filtering logic. Nearly identical across all scripts.

These go into R/respiration_helpers.R, sourced by the unified script.

Step 2: Unified 01_02 script

The unified script loads all needed packages at the top, then defines:

  1. process_ameriflux_core(name_site, site_info, a, ac, ...) — internal helper for the ~350 lines of AmeriFlux-specific logic (day/night calc, U-star filtering, site corrections, SWC interpolation, gap-filling). Returns list(ac, a_measure_night_complete, feature_row).
  2. process_site(name_site, overwrite) — main dispatcher following 01_01 pattern.

CLI parsing and site iteration at the bottom, same as 01_01.

Source-Specific Processing Differences (to preserve)

EuroFlux (FLUXNET/FLUXNET2015 sources)

  • Input: FLUXNET shuttle CSV (_FLUXMET_(HH|HR)_)
  • Column names: TA_F_MDS, TS_F_MDS_1, NEE_VUT_REF, etc.
  • TS corrections: CZ-Stn (use layer 2), FI-Sod (sensor change correction), GF-Guy (use TA)
  • estimate_Ts sites: read from workflow 01_01 output
  • Growing season threshold: FI-Sod/DE-RuC use NEE < 0.0 instead of max(min(NEE)*0.2, -0.8)
  • Gap thresholds: ZA-Kru/FI-Sod/GF-Guy get 60-day max gap
  • CH-Dav: min TS threshold of 2°C
  • Output columns: NEE_VUT_REF → NEE, TA_F_MDS → TA, etc.

AmeriFlux (AmeriFlux_BASE source)

  • Input: AMF_*_BASE*.zip via amerifluxr::amf_read_base()
  • Day/night from suncalc (sunrise/sunset), with Arctic daylight handling (US-ICt/ICh/ICs)
  • Variable mapping from site_info columns (NEE, FC, TA, TS, SWC, SW_IN, USTAR, RH/VPD)
  • US-Ha2: multi-tower merge (FC_1_1_1 + FC_2_1_1, etc.)
  • Extensive TS corrections: US-NR1/ICh/ICs (PI gap-fill), US-Cwt/US-MBP/US-BZo/CA-ARB/ARF/KLP/US-Rms/SRS/ChR (TA regression)
  • SWC interpolation (na.approx, maxgap=8)
  • U-star filtering via REddyProc (seasonal + yearly thresholds)
  • US-ChR: yearly U-star thresholds (no seasonal)
  • Tundra sites (US-ICh/ICt/ICs): use SW_IN < 10 | !daytime instead of !daytime
  • Gap thresholds: US-ICt/ICh/ICs, BR-Ma2/BR-Sa1 get 60-day max gap, 0.8 total
  • US-Ha1/US-GLE: min TS threshold of 2°C
  • Gap-filling TA/TS/NEE by DOY/HOUR/MINUTE mean
  • Output columns: NEE_uStar_f (not raw NEE), daytime, SW_IN

ICOS (ICOS source)

  • Input: Normalized ICOS L2 CSV (_ICOS_L2_FLUXNET_HH.csv)
  • Same FLUXNET column names as EuroFlux
  • Simpler pipeline: no U-star filtering, no day/night calculation, no SWC interpolation
  • Southern hemisphere: LAT < 0 (not hardcoded list)
  • Output: GPP_DT = NA_real_

TERN (TERN source)

  • Input: Normalized TERN CSV (_TERN_*_FLUXNET_HH.csv)
  • Simplest pipeline: no gap-filling, no year-gap filtering, no growing-season detection refinement
  • Only site: AU-Tum
  • Output: GPP_DT = NA_real_

Key Design Decisions

  1. Single process_site() with if/else dispatch, following 01_01 pattern. No separate top-level process_site_euroflux() etc. AmeriFlux complexity extracted into an internal helper process_ameriflux_core().
  2. Scalar site_info access: site_info <- get_site_info(name_site) returns single-row tibble. All access via $ or [["col"]]. Never use [id] indexing.
  3. Southern hemisphere: site_info[["LAT"]] < 0 consistently across all sources. No hardcoded site lists.
  4. Growing-season threshold: Preserved as-is per source. EuroFlux uses max(min(NEE)*0.2, -0.8); AmeriFlux uses min(NEE)*0.2. The detect_growing_season() helper accepts a threshold_fn parameter.
  5. Flat output directory: All sites write {site}_ac.csv and {site}_nightNEE.csv directly to data-proc/respiration/. No per-source subdirectories.
  6. Single feature file: One data-proc/features/growing_season_features.csv for all sites. Replaces four per-source files.
  7. Libraries loaded at top: All packages loaded unconditionally (dplyr, lubridate, optparse, amerifluxr, suncalc, REddyProc, lutz, zoo). Simpler than conditional loading.

Output Column Consistency

All sources already output the same column names. The key column NEE_uStar_f is consistent:

  • AmeriFlux: actual U-star filtered + gap-filled NEE from REddyProc
  • EuroFlux/ICOS/TERN: aliased from NEE_VUT_REF (no U-star filtering applied, but column name is the same)

Downstream workflows (02_01a, 02_01b, 03_01) all read NEE_uStar_f uniformly. No column renaming needed in the refactor.

  • Mitigation: Validate by comparing output CSVs between old and new scripts for representative sites from each source

Implementation Notes

Key Design Decisions

  1. AmeriFlux extracted into process_ameriflux_core(): The ~350 lines of AmeriFlux-specific logic (suncalc day/night, REddyProc U-star, site corrections, SWC interpolation, gap-filling) are wrapped in an internal helper that returns list(ac, a_measure_night_complete, feature). This keeps process_site() readable while preserving all original logic exactly.
  2. Source dispatch uses site_info[["source"]]: Single-row tibble access via $ or [["col"]]. Never [id] indexing. The if/else if chain dispatches on AmeriFlux_BASE, FLUXNET/FLUXNET2015, ICOS, TERN.
  3. Southern hemisphere via LAT < 0: Replaces all hardcoded site lists ("AU-Tum", "ZA-Kru"). Applied consistently in both a (full time series) and a_measure_night_complete (filtered observations).
  4. Growing-season threshold preserved per source: AmeriFlux uses min(NEE)*0.2; EuroFlux/ICOS/TERN use max(min(NEE)*0.2, -0.8). EuroFlux has additional site-specific overrides (FI-Sod/DE-RuC use NEE < 0.0). All passed via filter_fn parameter to detect_growing_season().
  5. Flat output directory: All sites write {site}_ac.csv and {site}_nightNEE.csv directly to data-proc/respiration/. No per-source subdirectories. Downstream workflows already discover files by recursive list.files pattern matching, so this is transparent.
  6. Single consolidated feature file: One data-proc/features/growing_season_features.csv replaces four per-source files. load_growing_season_features.R updated to read single file.

Challenges and Trade-offs

  1. AmeriFlux complexity: The U-star filtering block (~80 lines) with REddyProc setup, season factor creation, and threshold merging is the most delicate part. US-ChR uses yearly thresholds (no seasonal), while all other sites use seasonal. This branching is preserved exactly.
  2. ICOS dt calculation: ICOS uses dt * 1800 (seconds) for timestamp construction, while EuroFlux/TERN use dt / 2 (half the timestep). This difference is preserved in the respective blocks.
  3. Estimate_Ts file paths differ by source: AmeriFlux reads from data-proc/soil-temperature/AmeriFlux_BASE/{site}/; EuroFlux reads from data-proc/soil-temperature/{site}/. This is preserved in each source block.
  4. EuroFlux southern hemisphere DOY adjustment: Applied to both a and a_measure_night_complete separately (the latter only after filtering). ICOS applies it to a first, then to the filtered data. TERN doesn't apply it (AU-Tum is the only site, handled by ICOS path). These differences are preserved.
  5. Gap threshold sites differ by source: AmeriFlux large-gap sites: US-ICt/ICh/ICs, BR-Ma2/BR-Sa1 (60-day, 0.8 total). EuroFlux large-gap sites: ZA-Kru, FI-Sod, GF-Guy (60-day, 0.7 total). These are handled by compute_gap_thresholds() which takes source as a parameter.
  6. Missing closing parenthesis in AmeriFlux NEE FC check: Line 169 of original 01_02b had ac$NEE[is.na(a[, trimws(site_info$FC[id])])] <- NA with a missing closing bracket. Fixed in the unified script.
  7. get_site_info() returns NA_character_ for empty fields: The original scripts used != "" checks (from the old site_info[id] indexing pattern). Since readr::read_csv with "c" columns returns NA_character_ for empty cells, these were changed to !is.na(). The trimws() calls on column names were also removed — site_info.csv column names never have whitespace.
