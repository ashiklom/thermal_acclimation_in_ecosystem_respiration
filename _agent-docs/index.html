These documents describe the current state of the codebase and remain accurate.

  • Full Workflow Implementation Record

    Current

    Overall implementation plan and progress notes for the thermal acclimation pipeline. Documents the completed refactor to source-specific workflows (AmeriFlux, ICOS, TERN), the cross-site prior build, and the current state of execution readiness.

  • Data Directory Cleanup

    Current

    Records the data directory reorganization into data-core, data-raw, and data-proc. Describes the proposed layout, the implemented revision, and which scripts were updated to use new paths.

  • ICOS Sites: Download and Integration Status

    Current

    Documents the ICOS download scripts, L2 normalization, FLUXNET estimate-TS sites, and how to run the integration workflows. Covers both 01_01 and 01_02c.

  • ICOS Respiration Workflow

    Current

    Implementation record for the ICOS-only Workflow 01 path (01_02c). Covers input/output, processing steps, downloader changes, verification, and a five-site branch test.

  • TERN Download and Processing Workflow

    Current

    Documents the TERN download, normalization, site mapping, respiration processing (01_02d), soil temperature handling, growing-season diagnostics, and visualization. Note: contains an unclosed <pre> tag around line 98.

  • US-CMW Soil Water Content Ambiguity

    Current

    Analysis of the ambiguous SWC field mapping for US-CMW. Documents the audit, evidence, figures, and the provisional recommendation to use SWC_1_6_1.

  • Workflow 01 Refactor

    Current

    Historical record of the 01_01, 01_02a, and 01_02b refactor that added per-site execution, skip behavior, and overwrite support. The referenced scripts 01_02a was later deleted and replaced by 01_02c/01_02d, but the refactor pattern and CLI interface remain the same.

  • Workflow Description

    Current

    Comprehensive description of the full pipeline (Steps 01–04). Updated to reflect the current three-source architecture (01_02b AmeriFlux, 01_02c ICOS, 01_02d TERN) and the data-proc/ directory layout. Historical context about the legacy 01_02a (EuroFlux) workflow is preserved.

  • Workflow Improvements

    Current

    Tiered improvement recommendations for the pipeline. Updated to reference the current scripts (01_02b, 01_02c, 01_02d). Historical context about the legacy 01_02a is preserved in the document.

  • ICOS Level-2 Data Downloader

    Current

    Detailed documentation of the ICOS downloader (93-download-icos.py). Updated to reference 01_02c and the data-raw/ICOS/ directory layout. The downloader documentation (columns, API, authentication) remains accurate.
