Implementation Plan

  1. Update source dispatch and site selection so the supported branches are explicitly AmeriFlux, ICOS, and TERN, with validation that rejects legacy FLUXNET source values.
  2. Replace downstream reads of growing_season_feature_EuropFlux.csv with a combined feature loader for growing_season_feature_AmeriFlux.csv, growing_season_feature_ICOS.csv, and growing_season_feature_TERN.csv.
  3. Confirm that no active workflow depends on the legacy FLUXNET/EuroFlux step, delete it, and update active documentation and command references.
  4. Run workflows 01_01 and the applicable source-specific 01_02 scripts for every site in data/site_info.csv, preserving the existing skip/overwrite behavior and recording any code or data issues encountered.
  5. After the step-01 runs complete without errors, document the changes and required fixes in this file and create the first implementation commit.
  6. Refactor the pooled cross-site prior calculation from the following TAS workflow into a standalone script that loops over windows, writes the required prior coefficients to disk, and has a clear command-line entry point.
  7. Modify the immediately following site-specific TAS workflow to load those persisted priors, run all sites when no site argument is supplied, and run only the requested comma-separated sites when an argument is supplied, matching the 01-step interface.
  8. Run the standalone multi-site prior script and verify its persisted output before attempting site-level TAS fits.
  9. Select three representative sites covering the supported source branches and relevant edge cases, run the site-specific TAS step for those sites, and stop to fix any errors before scaling out.
  10. Once the three-site validation succeeds, run the site-specific TAS step for all remaining sites, update this record with commands, results, and any fixes, then create the requested commit.
