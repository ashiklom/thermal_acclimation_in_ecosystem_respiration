ICOS Sites: Download and Integration Status

This page records the current ICOS/FLUXNET acquisition and integration state after the downloader and Workflow 01 refactors.

ICOS L2 Normalization

workflows/93-download-icos.py queries the ICOS Fluxnet, Meteo, and Meteosens products and merges them on TIMESTAMP.

It writes files named {site}_ICOS_L2_FLUXNET_HH.csv under data-raw/SiteData/Ecosystem final quality (L2) product in ETC-Archive format - release 2025-1/unzip/.

The normalized file supplies the standardized fields needed by the EuroFlux workflows, including TA_F_MDS, NEE_VUT_REF, TS_F_MDS_1, SWC_F_MDS_1, NETRAD, and NIGHT.

FR-FBn validation: The downloader was tested successfully against FR-FBn and produced a 70,128-row, 30-minute normalized file with measured soil temperature. The generated file is ignored by Git because data-raw/ is ignored.
Important: FR-FBn still requires data-raw/TS_RandomForest/FR-FBn_TS_rfp.csv when running the ICOS-only respiration workflow. The normalized ICOS file solves the missing measured-TS input problem, but the prediction file must first be created by 01_01_estimate_soil_temperature_at_some_sites.R --sites=FR-FBn.

Running the Integration Workflows

Workflow 01 now accepts either --sites=SITE1,SITE2 or one positional comma-separated site list, plus --overwrite.

Rscript workflows/01_01_estimate_soil_temperature_at_some_sites.R --sites=FR-FBn
  Rscript workflows/01_02c_filter_high_quality_night_respiration_ICOS.R --sites=FR-FBn

Without a site argument, the scripts process all eligible sites. Existing per-site outputs and aggregate feature rows are skipped unless --overwrite is supplied.

The two respiration outputs are written to data-raw/RespirationData/{site}_ac.csv and data-raw/RespirationData/{site}_nightNEE.csv; growing-season features are written to the source-specific ICOS, TERN, or AmeriFlux CSV.

Known Limitations

  • icoscp selects the first object returned for each datatype; the API ordering should be checked if multiple product versions are available.
  • The normalized ICOS CSV is intentionally not a byte-for-byte archive copy; missing values use -9999.
  • The full EuroFlux respiration workflow has not been rerun as part of downloader validation.
  • Compound sources such as FLUXNET2025_ICOS2025 still require every referenced input file to be present; use a standalone normalized ICOS file only for sites configured to consume it.
