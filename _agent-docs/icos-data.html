ICOS Level-2 Data Downloader

workflows/93-download-icos.py downloads ICOS Ecosystem Thematic Centre level-2 products and writes a normalized, FLUXNET-style half-hourly CSV for each station. It is a uv standalone script, so dependencies are declared in the script header rather than in the project environment.

Test status: FR-FBn was downloaded successfully. The resulting file has 70,128 rows at a uniform 30-minute interval and contains all columns required by the EuroFlux workflows.

Running the Script

Run one or more sites explicitly:

uv run --script workflows/93-download-icos.py --sites FR-FBn FR-Fon

The script can also be made executable and run directly:

chmod +x workflows/93-download-icos.py
./workflows/93-download-icos.py --sites FR-FBn

When --sites is omitted, site IDs are extracted from the Id column of ~/Downloads/stations.csv.

OptionDescription
-s, --sites SITE [SITE ...]One or more ICOS ecosystem site IDs, such as FR-FBn.
-f, --site-list PATHStation metadata CSV used when --sites is omitted. Defaults to ~/Downloads/stations.csv.
-o, --overwriteReplace an existing normalized CSV. Without this flag, existing files are skipped.
-d, --output-dir PATHOutput directory. Defaults to data-raw/ICOS.

Authentication and API

The script uses icoscp and the current ICOS metadata/data APIs. It does not expose authentication arguments or credentials. Existing user-wide ICOS authentication is used by the installed package when data access requires it; metadata lookup itself is public.

For each site, the script queries these datatype resources:

ProductDatatype URI suffixUse in normalized file
FluxnetetcL2FluxnetAir temperature, incoming shortwave radiation, NEE, and their source QC fields.
MeteoetcL2MeteoOutgoing and incoming radiation components plus soil water content.
MeteosensetcL2MeteosensMeasured soil temperature. The first available column beginning with TS_ is used.

icoscp_core.icos.meta.list_data_objects() finds the product for the station URI ES_{site}. The first object returned by the API is selected, and its data are loaded through icoscp.dobj.Dobj(...).data as a pandas data frame.

Output Files

Each site produces one file:

{site}_ICOS_L2_FLUXNET_HH.csv

For example:

data-raw/ICOS/FR-FBn/FR-FBn_ICOS_L2_FLUXNET_HH.csv

The file is a merged and normalized product, not a byte-for-byte copy of an ICOS archive ZIP. Missing values are written as -9999, matching the convention used by the R workflows.

Processing Details

  1. The three ICOS products are joined on their shared TIMESTAMP field.
  2. Fluxnet field names are renamed to the FLUXNET-style names expected by the R workflows.
  3. The first available Meteosens TS_* field is used as TS_F_MDS_1.
  4. Meteo radiation fields are retained and combined into NETRAD.
  5. QC fields for soil temperature and soil water content are generated from data presence because the selected source fields do not provide the target FLUXNET QC names.
  6. The rows are sorted by timestamp and written with -9999 as the missing-value marker.

FR-FBn Validation

The tested FR-FBn source products were:

  • ICOSETC_FR-FBn_FLUXNET_FLUXMET_HH_2022-2025_v1.3_r1.zip
  • ICOSETC_FR-FBn_METEO_L2.zip
  • ICOSETC_FR-FBn_METEOSENS_L2.zip

The normalized FR-FBn CSV contains:

  • 70,128 half-hourly rows.
  • 30-minute spacing for every adjacent timestamp.
  • 54,384 nonmissing measured soil-temperature values in the selected source field.
  • 6,804 rows satisfying the main nighttime respiration filter conditions used by workflow 01_02.
FR-FBn workflow note: 01_02c_filter_high_quality_night_respiration_ICOS.R (formerly, 01_02a_filter_high_quality_night_respiration_EuroFlux.R) has a site-specific branch that replaces TS_F_MDS_1 with predictions from data-proc/soil-temperature/ICOS/FR-FBn/FR-FBn_TS_rfp.csv when that file is present. The downloaded CSV itself is compatible with the expected input schema and contains measured soil temperature, but the complete FR-FBn R workflow may still depend on that separate prediction file.

Workflow Compatibility

The output directory is intentionally the directory searched as ICOS input files by workflows 01_01_estimate_soil_temperature_at_some_sites.R and 01_02c_filter_high_quality_night_respiration_ICOS.R (which replaced the legacy 01_02a_filter_high_quality_night_respiration_EuroFlux.R).

The normalized file supplies the fields used by those workflows:

  • Workflow 01_01 uses TIMESTAMP_START, TS_F_MDS_1, TA_F_MDS, and NETRAD.
  • Workflow 01_02 uses TIMESTAMP_START, TA_F_MDS, TS_F_MDS_1, TS_F_MDS_1_QC, SWC_F_MDS_1, NEE_VUT_REF, NEE_VUT_REF_QC, and NIGHT.
  • Both workflows convert -9999 to NA after reading the CSV.

The full long-running R workflows were not run as part of downloader validation.
